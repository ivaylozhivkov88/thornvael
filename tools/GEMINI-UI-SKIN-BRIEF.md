# Gemini / Canva Brief: Dark-Fantasy UI Skin (Thornvael)

One image per prompt, ~2 min pause between prompts. Save raw downloads as `tools/.canva-sheets/ui-<name>.jpg`. Elements with transparent interiors or outer corners use a flat solid magenta (`#ff00ff`) background for clean alpha keying.

Common rules (inside every prompt): painted dark-fantasy RPG user interface art, hammered antique bronze and tarnished wrought-iron metalwork, worn dark slate and oiled parchment accents, sharp beveled edges, top-left specular highlight, no text, no numbers, no watermarks.

**panel-frame** — Generate an image, square 1:1. A single ornate square 9-slice dark-fantasy UI window frame on a flat solid magenta (`#ff00ff`) center and outer margin: dark hammered iron border with antique bronze corner rivets, filigree corner flourishes, subtle inner bevel, empty flat magenta interior so it can be sliced as a 9-slice CSS border-image. No text, no icons, painted RPG UI style.

No text, crisp pixel-clean edges, painted RPG UI style.
