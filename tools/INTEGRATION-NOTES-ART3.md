# Integration Notes: Wave 3 Art Packs & Base Item Icons (Thornvael)

All assets below are reproducibly generated by `tools/gen-art-wave3.py`, registered in `assets.json` (`license: "own"`, `< 3 MiB`), and verified by `tests/art-wave3.test.ts`. Future Gemini/Canva upgrades following `tools/GEMINI-WAVE3-BRIEF.md` should pack to the exact same slugs and frame keys so game code requires zero path edits.

## 1. Base Item Icons (`public/itemicons/<slug>.png`) -> `src/townui.ts` / `src/heroui.ts` / `src/shell.ts`

- **Coverage**: Adds **189** new 64x64 RGBA PNG icons without touching the 160 existing `manifest.json` icons (`349` PNGs total, `350` files including `manifest.json`).
  - `public/data/items.json`: **187 / 187** (100%) base weapons, shields/foci, helms, armors, boots, gloves, rings, amulets, potions/elixirs, and spell scrolls/tomes.
  - `public/data/content/base-items.json`: **160 / 160** (100%) name-slug coverage (completing `greased-archers-gloves.png`, `copper-sewn-gloves.png`, and `toll-collectors-belt.png` cited in `tools/WIKI-MISSING-IMAGES.md`).
- **Drop-in DOM helper**:

```ts
export const itemIconSlug = (name: string): string =>
  name
    .toLowerCase()
    .replace(/['’]/g, '')
    .replace(/[^a-z0-9]+/g, '-')
    .replace(/^-+|-+$/g, '');

export function createItemIconImg(itemName: string, sizePx = 48): HTMLImageElement {
  const img = document.createElement('img');
  img.src = `/thornvael/itemicons/${itemIconSlug(itemName)}.png`;
  img.width = sizePx;
  img.height = sizePx;
  img.alt = '';
  img.loading = 'lazy';
  img.decoding = 'async';
  img.className = 'tv-item-icon-img';
  return img;
}
```

- Pair with `.tv-rarity-<tier>` from `/thornvael/uiskin/uiskin.css` on the slot wrapper, keeping `itemIcon(item)` from `src/townicons.ts` as an instant SVG fallback on `onerror`.

bannerSprite.texture = envSheet.textures[`banner/${faction}/${bannerIdx}`];
bannerSprite.anchor.set(0.5, 0.94);

## 3. Boss AoE Telegraphs (`public/art-wave3/boss-telegraphs.{png,json}`) -> `src/render.ts` / `src/fx/`

- **Atlas**: `23` RGBA8888 decals packed into `public/art-wave3/boss-telegraphs.png` (`1024x512`).
- **Frame keys**:
  - Shared progression: `ring/outer`, `ring/fill-0`, `ring/fill-1`, `ring/fill-2`, `ring/fill-3` (`128x128`, `anchor: { x: 0.5, y: 0.5 }`), `line/beam` (`192x64`, `anchor: { x: 0.0, y: 0.5 }`), `cone/arc` (`128x128`, `anchor: { x: 0.08, y: 0.5 }`)
  - Act bosses (`morvessa`, `gorrathul`, `vesperion`, `ashkarath`):
    - `<boss>/ring` (`128x128`, `anchor: { x: 0.5, y: 0.5 }`)
    - `<boss>/cone` (`128x128`, `anchor: { x: 0.08, y: 0.5 }`)
    - `<boss>/line` (`192x64`, `anchor: { x: 0.0, y: 0.5 }`)
    - `<boss>/glyph` (`96x96`, `anchor: { x: 0.5, y: 0.5 }`)
- **Ability mapping (`src/sim/combat.ts` `bossTick`)**:
  - `morvessa`: `Poison Spray` -> `morvessa/cone`, `Spine Lash` -> `morvessa/line`, `Brood Hatch` -> `morvessa/ring` + `morvessa/glyph`.
  - `gorrathul`: `Holy Freeze Aura` -> `gorrathul/ring`, `Acid Cleave` -> `gorrathul/cone`, `Subterranean Charge` -> `gorrathul/line` + `gorrathul/glyph`.
  - `vesperion`: `Frost Nova` / `Soul Siphon` -> `vesperion/ring` + `vesperion/glyph`, `Grapeshot Sweeper` -> `vesperion/cone`, `Ball Lightning` -> `vesperion/line`.
  - `ashkarath`: `Fire Ring` / `Bone Prison` -> `ashkarath/ring` + `ashkarath/glyph`, `Hellfire Breath` -> `ashkarath/cone`, `Red Lightning` -> `ashkarath/line`.
- **Drop-in Pixi v8 wiring**:

```ts
const telegraphSheet = await Assets.load<Spritesheet>('/thornvael/art-wave3/boss-telegraphs.json');

// Render expanding circle telegraph on ground layer (below unit sprites):
const step = Math.min(3, Math.max(0, Math.floor(chargeRatio * 4)));
outerSprite.texture = telegraphSheet.textures[`${bossId}/ring`] ?? telegraphSheet.textures['ring/outer'];
outerSprite.anchor.set(0.5, 0.5);
outerSprite.scale.set(radiusPx / 58);

fillSprite.texture = telegraphSheet.textures[`ring/fill-${step}`];
fillSprite.anchor.set(0.5, 0.5);
fillSprite.scale.set(radiusPx / 58);

// Directional cone or line:
dirSprite.texture = telegraphSheet.textures[`${bossId}/${shape}`]; // 'cone' | 'line'
dirSprite.anchor.set(shape === 'cone' ? 0.08 : 0.0, 0.5);
dirSprite.rotation = Math.atan2(targetY - bossY, targetX - bossX);
```

## 4. Four-City Building Silhouettes (`public/art-wave3/city-buildings.{png,json}`) -> `src/render.ts` & `src/townui.ts`

- **Atlas**: `20` architectural building silhouettes packed into `public/art-wave3/city-buildings.png` (`1024x512`).
- **Frame keys** (`anchor: { x: 0.5, y: 0.90 }`):
  - `thornwick/{tavern,smithy,temple,gate,watchtower}` (Act I frontier timber & mossy slate)
  - `redmarsh/{tavern,smithy,temple,gate,watchtower}` (Act II alkali limestone, terracotta domes & quartz rods)
  - `oakhaven/{tavern,smithy,temple,gate,watchtower}` (Act III storm-slate & oxidized verdigris copper)
  - `ironcamp/{tavern,smithy,temple,gate,watchtower}` (Act IV jagged black basalt, iron ribs & molten vents)
- **Drop-in Pixi v8 wiring (`src/render.ts` `sim.towns` loop)**:

```ts
const citySheet = await Assets.load<Spritesheet>('/thornvael/art-wave3/city-buildings.json');

function resolveCityKey(townName: string): 'thornwick' | 'redmarsh' | 'oakhaven' | 'ironcamp' {
  const lower = townName.toLowerCase();
  if (lower.includes('redmarsh')) return 'redmarsh';
  if (lower.includes('oakhaven')) return 'oakhaven';
  if (lower.includes('ironcamp')) return 'ironcamp';
  return 'thornwick';
}

const ROLES = ['tavern', 'smithy', 'temple', 'gate', 'watchtower'] as const;
// Inside sim.towns loop at (c[0] * TILE, c[1] * TILE):
const cityKey = resolveCityKey(town.name ?? '');
const roleKey = ROLES[role % ROLES.length];
buildingSprite.texture = citySheet.textures[`${cityKey}/${roleKey}`];
buildingSprite.anchor.set(0.5, 0.90);
```
