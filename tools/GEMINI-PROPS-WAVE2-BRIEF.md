# Gemini / Canva Brief: World Props Wave 2 (Thornvael)

One image per prompt, ~2 min pause between prompts. Each image is a sheet of 6 separate objects in a 3x2 grid on a flat solid magenta (`#ff00ff`) background so `tools/obj-cut.py` (or `tools/gen-new-art-packs.py`) can key and pack them cleanly. Save as `tools/.canva-sheets/prop2-<name>.jpg`.

Common rules (inside every prompt): top-down 3/4 view like a classic dark-fantasy RPG, objects fully separated by generous magenta gaps, identical scale and lighting from the upper left, crisp dark outlines, no text, no ground patches, no drop shadows on the background, painted dark-fantasy style.
